# TraderX v1.0

The supported system and installation are described in the root README and START_HERE. Current acceptance results are in V1_FINAL_REPORT.md. Earlier research reports preserve measured experiments, including negative findings; their phase-specific acceptance counts are historical, not the current release result.

The application is paper-only. No model has demonstrated qualified independent after-cost alpha. Existing forward observations remain quarantined. Runtime data and credentials are private and excluded from Git.

The governed autonomous research phase extends this baseline. It is unpublished and paused by default. See AUTONOMOUS_RESEARCH.md for the executable scope and AUTONOMOUS_ACCEPTANCE.md for the final acceptance record.
