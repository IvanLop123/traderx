# Current provider purposes

| Provider | Current purpose | Availability |
|---|---|---|
| Coinbase public | Spot crypto history, quotes and optional sampled stream | Public; gaps remain explicit |
| Alpaca | US equity/ETF history, quotes, corporate actions, indicative options snapshots | Requires keys and relevant entitlements; session/feed limitations apply |
| Hyperliquid public | Crypto funding and public market context | Read-only; no execution |
| SEC | Timestamped filings and insider disclosures | Identifying contact required |
| FRED | Macroeconomic observations and initial-release research | Optional key; data vintages retained |
| EIA | Energy observations | Optional key; not assumed predictive |
| Manual import | Authorized unstructured research documents | Provenance required |

The System page classifies providers as working, optional, unavailable due to entitlement or disabled, alongside actual errors/timestamps. API access is not permission to redistribute datasets. Options are current descriptive observations, not a historical options backtest or order capability.
